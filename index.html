Transparencia y confianza

Tu información, con respeto

La Esquina de Augusto utiliza los datos que compartes únicamente para atender tu solicitud y brindarte el servicio que nos pides.

Qué datos usamos y para qué

Para una reserva solicitamos nombre, teléfono, fecha, hora, número de personas y, si deseas, una nota especial. Los usamos para registrar la solicitud, confirmar disponibilidad y coordinar contigo.

Almacenamiento y conservación

Las reservas se registran en Supabase, el servicio de base de datos conectado a este sitio. El proyecto contempla borrar reservas con más de 180 días cuando la tarea de mantenimiento esté habilitada.

Sin promociones no solicitadas

Los datos de tu reserva no se usan para enviarte promociones. Si eliges contactarnos por WhatsApp, se abrirá esa plataforma para que tú decidas si envías los detalles.

Solicita acceso o eliminación

Puedes pedir que revisemos, corrijamos o eliminemos tus datos escribiéndonos al WhatsApp del restaurante.

Este aviso describe el uso de datos en esta página. Los requisitos aplicables pueden variar según la legislación vigente.
